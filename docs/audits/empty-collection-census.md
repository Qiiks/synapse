# Empty-collection census

Audit snapshot: `e5d51cb626de6132e58de0581a528d430c61823c` (with the defect fix described below applied afterward).

## Scope and method

The census covers production Rust under:

- `crates/synapse-module/`
- `crates/synapse-core/`
- `crates/synapse-engine-owned/`

It searched iterator `.all(...)` and `.any(...)`, `.is_empty()` used in a boolean branch (including `filter`, `ensure!`, and `assert!` predicates), and `.iter().find(...).is_none()` approvals. `tests/` and `#[cfg(test)]` bodies are excluded. Examples and measurement-only harnesses are class 3. There are no production `.iter().find(...).is_none()` approval sites in scope.

A row can contain several adjacent predicates when they implement one decision. Every exact line is still named. A site is assigned its highest-consequence class: a predicate that both emits evidence and controls certification is class 1.

Verdicts mean:

- **DEFENDED** — empty input is rejected before the potentially vacuous predicate, or another mandatory conjunct at that decision makes empty fail closed.
- **CHOSEN** — the branch explicitly gives empty input a named meaning. This includes valid empty schemas, an absent optional constraint, an idle queue, or a deliberately empty result.
- **DEFECT** — reachable emptiness inherited a success value and permitted an action without evidence.

## Result

One defect was found and fixed. `Q8_0Tensor::quantize(&[], 32)` used to pass the complete-row and finite-value checks because `0 % 32 == 0` and `.all(is_finite)` is true for no values. It returned a zero-byte Q8 tensor to the production model-loading path. The encoder now refuses an empty matrix before either vacuous predicate.

The already-correct `release_ready` fix is confirmed: it iterates the non-empty constant `ALL_GATES`, not the evidence map, so an empty `gate_statuses` map performs twelve failed lookups and returns `false`.
